VeriCoder Architecture

编码 Agent → 可观测工具调用 → 四维验证 → 有界反馈 → 可追溯实验记录

验证与反馈闭环

  • • 原始测试、需求断言、补丁范围与真实工具轨迹共同提供证据。
  • • PASS / FAIL / WARNING / INVALID 区分完成、风险与证据缺失。
  • • 从固定基线重建候选，按预算限制反馈重试。

配对实验与可追溯性

  • • 四个实验条件共享首轮候选，保留补丁、工具轨迹与运行元数据。
  • • 本地证据包包含源码快照、manifest 与哈希；SQLite 按需存储。
  • • 支持盲审导出；公开数据与解释见 docs/validation.md。

当前边界

  • • 当前为工程原型；本地执行不具备安全沙箱保证。
  • • Docker 与官方 SWE-bench harness 尚无真实执行验证和得分。
  • • 合成检出率与单任务 API 试跑不能证明真实场景反馈增益。
